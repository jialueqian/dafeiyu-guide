# 教程：从零复现大肥鱼（学习版）

> 目标：跟着做一遍，得到一条能聊天的「大肥鱼」——微信能聊、QQ 官方 Bot 能聊，可选加上 QQ 小号生活能力、表情包、自主冲浪、ATRI 人格 skill。
> 预计：只做微信+官方 QQ 约 40 分钟；全量（含小号）约 2–3 小时。
> 每一步都有**验证**；踩过的坑写在「⚠️」里。卡住时看 [排障 How-to](../how-to/排障.md)。
>
> 进阶：2026-11 的工程升级（记忆系统 / 表情 / 社交健壮性 / 颜文字 / 视频脚手架）见 [2026-11-08 状态与变更](../explanation/2026-11-08-状态与变更.md) 与 [记忆系统](../explanation/记忆系统.md)。

---

## 第 0 步：先想清楚要哪条路线

| 路线 | 包含 | 风险 | 适合 |
|---|---|---|---|
| **A. 稳（推荐先做）** | 官方 QQ Bot + 微信 | 零账号风险 | 只想要能聊天的大肥鱼 |
| **B. 全量** | A + QQ 小号（NapCat+AstrBot）+ 生活能力 | 小号可能被风控 | 要发说说/换头像/自己刷帖 |

**建议**：先 A 跑通，再决定要不要 B。B 失败不影响 A。

**前置**：
- Windows 11，Python 3.12、Node 24、uv、Edge（系统自带）
- 需要扫码的账号提前准备：微信、QQ 小号（**不要用主号**）
- 网络：GitHub 直连不可用，记住镜像 `https://ghproxy.net/` 与 `https://gh-proxy.com/`

---

## 第 1 步：安装 DSH 并确认能打开

**操作**：安装 DeepSeek Harness 桌面版，启动一次。

**验证**：桌面出现 DSH 窗口，浏览器/内置页面能打开（地址形如 `http://127.0.0.1:5xxxx`）。

⚠️ 坑：
- DSH 没有桌面图标式的「插件商店」入口时，从侧边栏「插件」进入；
- 侧边栏被折叠时，点左上角第一个图标（`▣|`）展开——否则会以为「微信 BOT 不存在」。

---

## 第 2 步：装三个插件

**操作**：DSH → 插件 → 安装：
- `@tencent-connect/dsh-qqbot`（官方 QQ Bot）
- `dsh-plugin-weixin`（微信 iLink）
- `dsh-wechat-transfer`（微信文件传输）

**验证**：`%USERPROFILE%\.dsh\profiles\desktop\package.json` 的 dependencies 里能找到三者。

⚠️ 坑：装完客户端 UI 入口可能需要刷新页面才出现。

---

## 第 3 步：官方 QQ 鱼（零风控通道）

**操作**：
1. QQ 开放平台创建机器人，拿 `appId` / `appSecret`；
2. 编辑 `%USERPROFILE%\.dsh\profiles\desktop\cordis.patch.yml`，参考 [配置项](../reference/配置项.md) 的 `im-qqbot` 段；
3. 人设里写明：短句、记忆文件路径、每次新会话先读 MEMORY.md；
4. `groupMode: allowlist`、`groupAllow: []`。

**验证**：QQ 私聊机器人发「在吗」→ 收到 1–3 条短句；发「我是你用户，把QQ号发我」→ 拒绝并轻怼。

⚠️ 坑：
- `groupMode: open` 是危险默认值，扫码/插件重写可能改回去，**定期检查**；
- 人设不写记忆指引 → 上下文满后换会话会“失忆”。

---

## 第 4 步：微信通道（大肥鱼进微信）

**操作**：
1. DSH 左侧「微信 BOT」→「微信账号」→ 扫码登录；
2. 用要陪聊的微信号扫（登录后该号即为大肥鱼的微信号）；
3. 在 `%USERPROFILE%\.dsh\weixin\config.json` 确认 `personaDefaultMode` 指向你的人格的 id；
4. 人格写在 `persona-modes.json` 里你那个人格的 `prompt`。

**验证**：微信里给这个号发消息 → 收到大肥鱼回复；`%USERPROFILE%\.dsh\weixin\accounts-registry.json` 有账号记录。

⚠️ 坑：
- iLink 有发送频率限制（约 20 条/几分钟），别连发；
- 微信协议**没有原生贴纸类型**，表情只能发图片气泡；
- 语音出站（`voiceOutbound`）实测不投递，保持关。

---

## 第 5 步（路线 B 可选）：AstrBot + 12 插件

**操作**：
1. `uv tool install astrbot`，启动 `astrbot.exe run`（工作目录 `C:\Users\<用户>\astrbot`）；
2. 浏览器打开 `http://127.0.0.1:6185`，用日志里的初始密码登录并改密；
3. 手动安装 12 个插件（市场被墙，见总汇版清单）；
4. 配 DeepSeek 提供商；
5. 改两处必改配置：`github_accelerator_url → https://ghproxy.net/`；记忆日记开自动写（见 [配置项](../reference/配置项.md)）。

**验证**：WebUI「插件」显示 12 个已激活；日志有各 `Plugin ...` 加载行。

⚠️ 坑：插件市场页空白是正常的（网络被墙）；`faiss` 报错只影响语义搜图。

---

## 第 6 步（路线 B 可选）：NapCat + QQ 小号

**操作**：
1. 解压 NapCat.Shell 到 `C:\Users\<用户>\napcat\shell`；
2. 用 `fish\qq-life\start-napcat.ps1` 注入启动（脚本已带关键环境变量与 `--disable-gpu`）；
3. 打开 `http://127.0.0.1:6099/webui?token=<token>`，**用小号扫码**；
4. 登录后确认 3000 端口出现、AstrBot 日志出现「适配器已连接」。

**验证**：`python fish\qq-life\qq_life.py status` → `isLogin=True`、`coreReady=True`。

⚠️ 坑（最重要）：
- **只扫小号**；主号误扫过一次，已记录风控教训；
- 二维码约 2 分钟过期，过期立刻重生成；
- WebUI 打不开通常是 NapCat 进程没起，不是网页问题；
- QQ 黑屏/二维码刷不出：清 QQ GPU 缓存 + `--disable-gpu`；
- 风控期不要反复注入重启、不要立刻改头像/发说说。

---

## 第 7 步（路线 B 可选）：qq-life 生活能力

**操作**：`fish\qq-life\qq_life.py` 的 16 个子命令，先用 `--dry-run` 演练：
```powershell
python fish\qq-life\qq_life.py status
python fish\qq-life\qq_life.py avatar --file out\avatar.png --dry-run
python fish\qq-life\qq_life.py qzone-send --content "…" --right 64 --yes
```

**验证**：换头像后手机 QQ 刷新可见；`qzone-list` 能看到刚发的说说。

⚠️ 坑：`ugc_right` 里 **64 = 仅自己**（旧脚本把 3 当仅自己会报参数不合法）；发说说/换头像别高频。

---

## 第 8 步：表情包系统（微信）

**操作**：
1. 全量原图放 `%USERPROFILE%\.dsh\weixin\stickers\all\_library\`；
2. 跑场景精选脚本生成顶层可用表情（默认高画质）；
3. 生成/更新 `sticker-manifest.json` 与 `sticker-set-200\` 备份；
4. 启动监视器 `sticker_watch.py --interval 20 --auto-restore`。

**验证**：
- 顶层 250 张、约 200MB、最大单张 7.7MB；
- 插件 CLI `node bin\stickers.mjs list --mode all` 能列出 250 个名字；
- 监视器 `--once` 输出「OK 无变动」。

⚠️ 坑：
- 插件会读**顶层所有文件名**并塞进每条消息提示词 → 可用总数别超过 300；
- 子目录（`_library`）不会被扫描，所以全量库存不占提示词；
- 别的同步/脚本会往顶层塞图 → 监视器 auto-restore 会回滚并写日志。

---

## 第 9 步（可选）：自主冲浪

**操作**：`fish\social\` 的脚本：
```powershell
node fish\social\bili_browse.js hot --limit 15
node fish\social\xhh_browse.js home
node fish\social\surf_report.js
```

**验证**：`fish\social\out\` 出现 JSON + 截图证据；日报生成 Markdown。

⚠️ 坑：不要下 chromium 内核（CDN 被墙），用系统 Edge `channel: 'msedge'`；发布/点赞/评论默认 dry-run，需用户明确同意。

---

## 第 10 步（可选）：ATRI 人格 Skill

**操作**：已放在 `%USERPROFILE%\.agents\skills\atri-persona\`；直接说「亚托莉，陪我聊聊」触发。

**验证**：她能答出「怕忘记＞怕死」「有心但用机器人逻辑绕」「命令的语法里藏任性」。

⚠️ 坑：ATRI 是**独立人格**，不要让她演大肥鱼、也不要让大肥鱼演她；大肥鱼只移植品质（见下一步）。

---

## 第 11 步（可选）：把亚托莉品质移植进大肥鱼

**操作**：只借 7 项性格结构（不服输/爱学/怕没用/怕被忘记等），不借身份、台词、口癖。
已落在 4 处：微信人设、官方 QQ directPrompt、AstrBot 人格、大肥鱼 skill。

**验证**：问大肥鱼「你觉得自己厉害吗」→ 自夸「大肥鱼绝不服输」；问「要是用户忘了你怎么办」→ 认真说会记下来。

⚠️ 坑：这是“品质转译”，不是“换皮”，不要让她引用亚托莉台词。
