## 维护规则

1. **一个主题只放一个类型**：教程不写排障，排障不写原理；跨类型用链接。
2. **每步带验证**；风险操作标 ⚠️；密钥只写位置不写明文。
3. **术语统一**（见 `reference/术语表.md`）；新词先登记再使用。
4. **参考页是唯一事实源**：端口/路径/命令改了，先改 reference，再让其他文档引用。
5. 提交前跑 `cn-doc-style-guide check`（如已安装）。
