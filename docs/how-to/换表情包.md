# 如何换表情包

> 适用：想给微信大肥鱼增加/替换/精简可用表情。原则：**顶层可用 ≤300 张**，其余放 `_library` 不占提示词。

## 适用 / 不适用

- 适用：新增一批、换一套风格、删掉不喜欢的、修被别的脚本污染；
- 不适用：想发微信原生贴纸（协议不支持）；想绕过监视器偷偷改目录（会被回滚）。

## 前置

- 微信插件已装、`~/.dsh/weixin/stickers/` 存在；
- 已知当前状态：250 张 / 约 236MB / 最大 7.7MB；只留 DS 系（blue-fat-fish、deepseek-fanart）+ ATRI，官方包 official-001 已删除（2026-11-07）；
- 监视器在跑（`sticker_watch.py`，带 `--auto-restore`）。

## 步骤

1. **先停监视器**（否则改动会被回滚）：
   ```powershell
   Get-CimInstance Win32_Process -Filter "Name='pythonw.exe'" |
     Where-Object { $_.CommandLine -match 'sticker_watch' } |
     ForEach-Object { Stop-Process -Id $_.ProcessId -Force }
   ```
2. **准备素材**：把原图放进 `~/.dsh/weixin/stickers/all/_library/<包名>/memes/<分类>/`。
3. **从 `_library` 精选**（会清空顶层并重建 200 张场景表情）：
   ```powershell
   python fish\wechat\curate_wechat_stickers.py --count 250
   ```
   或只补 50 张：
   ```powershell
   python fish\wechat\add_50_stickers.py
   ```
4. **高画质导出**（若素材被压过）：`python fish\wechat\upgrade_sticker_quality.py`
5. **重建清单和备份**（用 `rebuild_sticker_manifest.py` 一步重建）：
   ```powershell
   python fish\wechat\rebuild_sticker_manifest.py
   ```
   - 会重写 `fish\wechat\sticker-manifest.json`（watcher 以此为准）；
   - 会重建 `fish\wechat\sticker-set-200\`（自愈备份）。
6. **重启监视器**：
   ```powershell
   python fish\wechat\sticker_watch.py --interval 20 --auto-restore
   ```
7. **验证**：
   ```powershell
   python fish\wechat\sticker_watch.py --once      # 应输出 OK 无变动
   cd %USERPROFILE%\.dsh\profiles\desktop\node_modules\dsh-plugin-weixin
   node bin\stickers.mjs list --mode all           # 名字应能列出
   ```

## 大肥鱼想自己换怎么办

她应写 `~/.dsh/weixin/stickers/REQUEST.txt`（说想换什么、为什么）→ 监视器归档到 `fish\wechat\sticker-requests\` 并写告警；**不会自动执行**，等用户批准。

## 回滚 / 恢复

- 某次改动不想要：用 `sticker-set-200\` 覆盖顶层，再 `sticker_watch.py --once` 核对；
- 被别的同步塞进来的图：`_unapproved/` 里找；不用的可删；
- 清单坏了：重跑 `upgrade_sticker_quality.py` 或 `curate_wechat_stickers.py` 重建。
