# 如何排查故障

> 适用：大肥鱼某个通道不工作、页面打不开、报错、行为异常。先做「30 秒体检」，再按现象查表。

## 30 秒体检

```powershell
# 1) 端口
Get-NetTCPConnection -State Listen |
  Where-Object { $_.LocalPort -in 6185,6199,6099,3000 } |
  Select-Object LocalPort

# 2) AstrBot WebUI
(Invoke-WebRequest http://127.0.0.1:6185 -UseBasicParsing -TimeoutSec 5).StatusCode

# 3) 小号（NapCat 在线时）
python fish\qq-life\qq_life.py status

# 4) 表情监视
python fish\wechat\sticker_watch.py --once
```

| 缺失项 | 含义 |
|---|---|
| 6185 不通 | AstrBot 没起 |
| 6099 不通 | NapCat 没起（QQ 小号离线） |
| 3000 不通 | NapCat 起了但 QQ 没登录成功 |
| 6199 不通 | AstrBot 没起 |

## 按现象查

| 现象 | 最可能原因 | 处理 |
|---|---|---|
| 微信大肥鱼不回 | DSH 微信插件掉线 / 白名单 | DSH 侧栏看微信 BOT 状态；看 `~/.dsh/weixin/accounts-registry.json` |
| 微信 BOT 入口看不到 | 侧边栏被折叠 | 点左上角 `▣|` 展开 |
| 微信发不出/很慢 | iLink 限频 / 大 GIF | 降低频率；大图降到 720px |
| 官方 QQ 鱼群聊乱回 | `groupMode: open` | 改回 `allowlist`，`groupAllow: []` |
| QQ 小号 WebUI 打不开 | NapCat 进程没起 | `start-napcat.ps1 -Stop` 再 `start-napcat.ps1` |
| 二维码刷不出 / 刷新超时 | QQ 黑屏、GPU 渲染失败 | 清 `%APPDATA%\QQ\GPUCache`、`Code Cache` 等 + `--disable-gpu` 重启 |
| 二维码已过期 | 超过约 2 分钟 | `qq_life.py qr --refresh` 重新生成并立即扫 |
| NapCat 登录服务无响应 | Worker 多进程模式 | 确认 `NAPCAT_DISABLE_MULTI_PROCESS=1` |
| WebUI 提示 login rate limit | 登录限流 | 调高 `webui.json` 的 `loginRate` |
| AstrBot 日志 `10054` / 索引拉取失败 | GitHub 被墙 | 表情包加速换 `ghproxy.net`；插件市场基本不可用 |
| AstrBot WebUI 登录 401 | 密码已改/忘记 | 初始密码在 `astrbot/data/logs/astrbot-run.log`；改密前先备份 `cmd_config.json` |
| 表情包装不上/下载慢 | 镜像限速 | 用 `mirror_meme_packs.py` 本地镜像；或只装需要的包 |
| 可用贴纸变多、回复变慢 | 提示词里表情名过多 | 总数控制 ≤300；用 `curate_wechat_stickers.py` 重建 |
| 贴纸目录被塞图 | 别的同步脚本写入 | 看 `STICKER-DRIFT.log`；auto-restore 应已回滚；必要时手动清 `_unapproved/` |
| 上下文满后“失忆” | 没有记忆落盘/注入 | 检查记忆日记配置；官方 QQ 鱼让它在 QQ 里发 `/compact` |
| 换了头像/资料没生效 | 小号离线或风控 | 看 `qq_life.py status`；风控期停手 |
| 脚本解析报错（中文乱码） | Windows PowerShell 5.1 + UTF-8 无 BOM | 脚本存成 UTF-8 with BOM，或改用 pwsh 7 |
| `Get-ChildItem -Include` 数出 0 | 路径没带通配 | 用 `Where-Object { $_.Extension -eq ... }` 或路径加 `\*` |
| .NET 文件操作找不到相对路径 | `[IO.File]` 用进程 CWD | 一律用绝对路径 |
| webp 图片打不开 | System.Drawing 不支持 | 用 Pillow（PIL）处理 |

## 升级为“要人看”的故障

以下情况停下来找用户/找文档，不要硬试：
- QQ 风控提示（环境异常、需要验证）→ 见 [恢复QQ小号](恢复QQ小号.md)；
- 任何要向主号扫码的操作 → 拒绝；
- 需要改支付/账号密码/密钥 → 拒绝。
