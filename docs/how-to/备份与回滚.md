# 如何备份与回滚

> 适用：改配置/改人格/换表情/升级前留后路；出问题能恢复。

## 必备份的 7 样

| # | 对象 | 路径 |
|---|---|---|
| 1 | DSH 官方 QQ 鱼配置 | `%USERPROFILE%\.dsh\profiles\desktop\cordis.patch.yml` |
| 2 | 微信桥配置 | `%USERPROFILE%\.dsh\weixin\config.json` |
| 3 | 微信人格 | `%USERPROFILE%\.dsh\weixin\persona-modes.json` |
| 4 | AstrBot 人格/配置 | `%USERPROFILE%\astrbot\data\data_v4.db` + `data\cmd_config.json` |
| 5 | 表情清单 | `fish\wechat\sticker-manifest.json` |
| 6 | 表情备份 | `fish\wechat\sticker-set-200\`（250 张） |
| 7 | 文档 | `fish\docs\`、`fish\大肥鱼复现指南-总汇版.md` |

## 备份命令

```powershell
$b = "D:\backup\dafeiyu-$(Get-Date -Format yyyyMMdd-HHmm)"
New-Item -ItemType Directory -Force -Path $b | Out-Null
Copy-Item "$env:USERPROFILE\.dsh\profiles\desktop\cordis.patch.yml" $b
Copy-Item "$env:USERPROFILE\.dsh\weixin\config.json" $b
Copy-Item "$env:USERPROFILE\.dsh\weixin\persona-modes.json" $b
Copy-Item "%USERPROFILE%\astrbot\data\data_v4.db" $b
Copy-Item "%USERPROFILE%\astrbot\data\cmd_config.json" $b
Copy-Item "fish\wechat\sticker-manifest.json" $b
Copy-Item "fish\wechat\sticker-set-200" $b -Recurse
Copy-Item "fish\docs" $b -Recurse
Write-Host "备份完成: $b"
```

## 改之前的习惯

1. **改 AstrBot DB 前先停服**：`fish\astrbot\stop-fish.ps1`；
2. 脚本自带 `.bak-*` 的（如 `data_v4.db.bak-infuse`、`persona-modes.json.bak-*`），别删；
3. 改 YAML/JSON 后先校验：`node .tools\yaml-check.js` / PowerShell `ConvertFrom-Json`；
4. 改表情前停监视器（见 [换表情包](换表情包.md)），否则会被回滚。

## 回滚步骤

| 改坏了什么 | 回滚 |
|---|---|
| 官方 QQ 鱼配置 | 停 DSH 插件/重启 DSH，用备份覆盖 `cordis.patch.yml` |
| 微信人格 | 用 `persona-modes.json` 备份覆盖（实时生效） |
| AstrBot 人格 | 停服 → 覆盖 `data_v4.db` → 启动 |
| 表情 | 用 `sticker-set-200\` 覆盖顶层 → `sticker_watch.py --once` |
| 文档 | 用 `fish\docs` 备份覆盖 |

## 注意

- 备份里含密钥/账号信息，**不要提交到公开仓库或发给别人**；
- 二维码、DB 里可能有登录态，按敏感文件处理；
- 回滚后做一次「30 秒体检」（见 [排障](排障.md)）。
