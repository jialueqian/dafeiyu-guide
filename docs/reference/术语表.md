# 术语表

> 新词先登记再使用；不同文档用词以本表为准。

| 术语 | 含义 | 不要混用 |
|---|---|---|
| **大肥鱼** | 本项目的 AI 小鲸鱼人格（自己起的名字；外面叫“大肥鱼”） | 不要写成“肥鱼本体”“鱼”单独指代 |
| **大肥鱼** | 大肥鱼的外号/网友叫法；也是人设里的自称来源 | 与“大肥鱼”同指一物，正式名用大肥鱼 |
| **ATRI / 亚托莉** | 《ATRI -My Dear Moments-》的角色；我们有独立 skill，**不让两个角色互相扮演** | 不要把 ATRI 当大肥鱼的空壳/皮肤 |
| **DSH** | DeepSeek Harness 桌面版，本机 AI 运行环境 | 不要写成“DS”或“DeepSeek 客户端” |
| **官方 QQ Bot（官方鱼）** | 走 QQ 开放平台官方协议的大肥鱼通道，零风控风险 | 不要叫“QQ 主号” |
| **QQ 小号 / 协议端** | 用 NapCat 注入 QQNT 的真实小号（<小号昵称> <小号QQ>），风控风险高 | 不要称“机器人号” |
| **大号 / 主号** | 用户自己的 QQ，只用官方 Bot 聊天，**绝不扫进协议端** | — |
| **微信桥（iLink）** | `dsh-plugin-weixin`，通过 iLink/ClawBot 绑定微信 | 不要叫“微信官方接口” |
| **AstrBot** | 本地 Python 服务（6185），给 QQ 小号提供 12 个插件 | 不要与 DSH 混淆 |
| **NapCat** | QQNT 注入式协议端（6099/3000），给 AstrBot 提供 OneBot 接口 | 不要称“QQ 插件” |
| **OneBot v11** | 协议端与 AstrBot 之间的消息协议（反向 WS 6199） | — |
| **表情图 / 表情包** | 微信里用 `[表情:名字]` 发出的图片气泡 | 微信**没有**原生贴纸类型，不能发“点开动画的收藏表情” |
| **原生贴纸** | 微信客户端自带的表情包类型；bot 协议不支持 | — |
| **表情层 / 记忆层 / 主动消息层** | 第四会话给微信桥补的三块能力（dsh-weixin-extras） | 不要与会话“人格”混用 |
| **记忆日记** | 上下文将满/每日 22:00 写日记、新会话注入的机制 | 不要叫“聊天记录备份” |
| **上下文压缩** | AstrBot `llm_compress`：打满先摘要压缩，保留最近 15% | 与“清空会话”不同 |
| **auto-restore** | `sticker_watch.py --auto-restore`：目录被改时自动回滚到授权 250 张 | 不是“自动换表情” |
| **REQUEST.txt** | 大肥鱼想换表情包时写的请求文件，watcher 归档，不自动执行 | — |
| **品质移植** | 只把 ATRI 的 7 项性格结构转译进大肥鱼，不借身份/台词/口癖 | 不要叫“人格融合/扮演” |
| **风控** | QQ/微信对异常登录环境的限制；本机小号 2026-11-07 被风控 | — |
| **ghproxy** | GitHub 镜像（`ghproxy.net`/`gh-proxy.com`），本机唯一可用下载途径 | — |

## 命名规范

- 文件/目录：中文名可用，但脚本参数与命令里尽量用英文路径变量；
- 表情文件名：`<场景>-<序号>.<ext>`，如 `害羞-03.gif`（= 微信表情名）；
- 机器可读标识（端口/路径/命令/ID）保持原样，不要翻译或加空格。
