# 配置项参考

> 只记录**改什么、改哪里、关键值**；完整结构以文件本身为准。改前先备份。

## DSH · 官方 QQ 鱼

文件：`%USERPROFILE%\.dsh\profiles\desktop\cordis.patch.yml`

```yaml
- id: im-qqbot
  config:
    appId: "<QQ开放平台 AppID>"
    appSecret: "<AppSecret>"
    preset: standard
    directPrompt: |   # 人设 + 记忆维护 + 颜文字频率
    groupPrompt: |    # 群聊短提示
    access:
      c2cMode: allowlist
      c2cAllow: ["<主人QQ的OpenID>"]
      groupMode: allowlist
      groupAllow: []   # 空 = 群聊不响应
```

**注意**：`groupMode: open` 可能被扫码/插件重写，定期检查保持 `allowlist`。

## DSH · 微信桥

文件：`%USERPROFILE%\.dsh\weixin\config.json`

| 键 | 建议值 | 说明 |
|---|---|---|
| `enabled` | true | 开关 |
| `personaDefaultMode` | `<你的默认人格 id>` | 默认人格 |
| `allowedSenders` | `[]` | 空=首条消息自动进白名单；可显式填 |
| `groupChatEnabled` | false | 群聊默认关 |
| `memoryEnabled` | true | 记忆落盘 |
| `humanPacing` / `lifeState` | true | 真人节奏/生活状态 |
| `stickerEnabled` | true | 允许 `[表情:名字]` |
| `stickerKeepBuiltins` | true | 保留内置 68 张 |
| `voiceOutbound` | false | 语音出站实测不投递，保持关 |

人格文件：`persona-modes.json` → `modes[]` 里你那个人格的 `prompt`（**每条消息实时读取**，改完即生效）。

## AstrBot

文件：`%USERPROFILE%\astrbot\data\cmd_config.json`

- `agent_runner.config.compression`：`overflow_strategy: "llm_compress"`、`fallback_max_tokens: 128000`、`keep_recent_ratio: 0.15` → 上下文打满先压缩。
- `provider_settings`：DeepSeek 提供商（`base_url=https://api.deepseek.com/v1`，模型 `deepseek-flash`）。

文件：`data\config\astrbot_plugin_memory_diary_config.json`

| 键 | 值 | 说明 |
|---|---|---|
| `context_token_limit` | 60000 | 触发预算 |
| `auto_ratio` / `remind_ratio` | 0.9 / 0.75 | 90% 自动写日记，75% 提醒 |
| `enable_context_watch` | true | 上下文哨兵 |
| `enable_auto_inject` | true | 新上下文注入 |
| `inject_default_days` / `inject_max_chars` | 7 / 8000 | 注入最近 7 天、≤8000 字 |
| `enable_auto_diary` / `auto_diary_time` | true / 22:00 | 每日全量日记 |

文件：`data\config\astrbot_plugin_meme_manager_config.json`

| 键 | 值 | 说明 |
|---|---|---|
| `community.github_accelerator_url` | `https://ghproxy.net/` | 必须改，默认 `ghfast.top` 会 10054 |
| `generation.emotion.probability` | 100 | 配图触发概率 |
| `generation.emotion.max_memes_per_message` | 1 | 每次最多 1 张 |
| `generation.prompt.quantity_guidance_enabled` | true | 启用频率引导 |

## NapCat

文件：`napcat\shell\config\webui.json`：`token`（自定）、`host: 127.0.0.1`、`port: 6099`、`loginRate` 可调高。
文件：`napcat\shell\config\onebot11.json`：反向 WS `ws://127.0.0.1:6199/ws`；HTTP `127.0.0.1:3000` + token。

## 表情系统

文件：`fish\wechat\sticker-manifest.json`（250 张名字+大小+sha256，**勿手改**，由脚本重建）。
文件：`fish\wechat\sticker-set-200\`（250 张备份，auto-restore 用）。
文件：`fish\wechat\sticker_tools.py`（高画质导出默认：静态 ≤1280、GIF ≤960/≤120 帧、超 8MB 降档）。
请求通道：`%USERPROFILE%\.dsh\weixin\stickers\REQUEST.txt`（大肥鱼写，watcher 归档到 `fish\wechat\sticker-requests\`）。
