# 命令速查

> 所有命令默认在 PowerShell 中执行；路径以本机为例，换机器时替换 `<用户名>`。

## 启动 / 停止

```powershell
# AstrBot（只启动，不碰 QQ）
fish\astrbot\start-fish.ps1 -AstrBotOnly
fish\astrbot\stop-fish.ps1

# NapCat + QQ 小号（会占用本机 QQ；风控期不要用）
fish\qq-life\start-napcat.ps1
fish\qq-life\start-napcat.ps1 -Stop

# 表情监视器
Get-CimInstance Win32_Process -Filter "Name='pythonw.exe'" |
  Where-Object { $_.CommandLine -match 'sticker_watch' } |
  ForEach-Object { Stop-Process -Id $_.ProcessId -Force }
python fish\wechat\sticker_watch.py --interval 20 --auto-restore
```

## 健康检查

```powershell
# 端口：6185 / 6199 / 6099 / 3000（登录后）
Get-NetTCPConnection -State Listen |
  Where-Object { $_.LocalPort -in 6185,6199,6099,3000 } |
  Select-Object LocalPort

# QQ 小号状态（需 NapCat 已登录）
python fish\qq-life\qq_life.py status

# 表情监视单次检查（应输出 OK 无变动）
python fish\wechat\sticker_watch.py --once
```

## 表情包

```powershell

python fish\wechat\sticker_watch.py --once
python fish\wechat\sticker_watch.py --interval 20 --auto-restore

# 场景精选重建（会清空顶层后重建 200 张）

```
