# 端口与路径参考

> 唯一事实源：端口/路径变更先改本页，其他文档只引用。

## 端口

| 端口 | 服务 | 说明 |
|---|---|---|
| 6185 | AstrBot WebUI | 账号 `astrbot`；初始密码在 `astrbot/data/logs/astrbot-run.log`（首次登录务必改密） |
| 6199 | AstrBot OneBot v11 反向 WS | NapCat 连这里 |
| 6099 | NapCat WebUI | token 在 `napcat/shell/config/webui.json` |
| 3000 | NapCat HTTP API | 仅 QQ 登录后监听；token 在 `onebot11.json` |
| 动态 | DSH Web GUI | 启动时输出 URL（本机曾为 65112） |
