# FAQ 常见问题

## 从哪开始？

看 [从零复现教程](../tutorials/01-从零养成大肥鱼.md)。只想要微信/QQ 聊天，走「路线 A」即可；要发说说/换头像再加「路线 B」。

## 为什么 README 不放聊天截图？

本仓库优先保证**可复现与可维护**，不放大体积截图；需要视觉参考时，文档里用命令行输出、结构图和表格代替。后续可选加脱敏截图。

## 能商用吗？

- 代码/工具：MIT，可商用（保留版权声明）。
- 文档内容：CC BY-NC-SA 4.0，**不可直接商用**，需署名并以相同方式共享。
- 角色相关素材（ATRI、DeepSeek 标识）版权归原权利人，不要商用。

## 我按教程做，但某一步卡住了

先看 [排障](../how-to/排障.md) 的「30 秒体检」；再看对应通道的 How-to。提交 issue 时附：系统版本、命令、完整报错、已尝试步骤。

## QQ 小号被风控了怎么办？

见 [恢复 QQ 小号](../how-to/恢复QQ小号.md)：立即停协议端 → 手机官方 QQ 养号 3–7 天 → 恢复后先只登录、不做写操作。**永远不要用主号扫码**。

## 表情包会不会让提示词变长？

会。微信插件把所有可用表情名塞进每条消息提示词，所以**顶层可用数建议 ≤300**；其余放 `_library`（不扫描、不占提示词）。

## 文档里的链接失效了？

仓库对指向仓库外的内部资料链接做了降级（显示为「仓库外资料，未收录」）。发现其他失效链接请提 issue 或 PR。

## 如何更新文档？

1. 改 `docs/` 下的 Markdown；
2. 本地预览：`python tools/md2html.py docs site` 或 `mkdocs serve`；
3. 运行 `python tools/check_links.py docs`；
4. 提 PR。
